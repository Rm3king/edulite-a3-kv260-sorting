# 三分钟演示视频制作说明

本包使用 [三分钟旁白与剪辑安排](narration_3min.txt)。`narration_full.txt` 保留为兼容入口，内容与该文件一致。

建议成片约 2 分 52 秒。具体镜头长度随实际录音调整，总长控制在 3 分钟以内。

| 时间 | 内容 | 重点画面 |
|---|---|---|
| 0:00—0:10 | 作品开场 | 名称、整机全景 |
| 0:10—0:34 | 架构与计算分工 | AI PC、KV260、NPU/GPU/CPU/ARM/FPGA |
| 0:34—0:48 | 硬件 | 两路相机、控制板、六轴与夹爪 |
| 0:48—1:03 | 上位机、零重力示教 | 拖动、数字孪生、记录按钮 |
| 1:03—1:28 | 识别与对准计算 | 分类轮廓、腕部掩码、误差箭头和曲线 |
| 1:28—2:18 | 基础抓取 | 中文指令、执行进度、抓取放置、核验复核 |
| 2:18—2:42 | 指定小螺母 | 混合场景、类别筛选、连续搬运 |
| 2:42—2:52 | 结尾 | 结果、托盘与整机 |

## 旁白与画面配合

旁白解释当前功能，短字幕补充型号、分工和性能。输入指令、腕部对准、放置核验这几个关键节点同步；转运过程中留出观察动作的时间。上位机的进度与识别数量集中介绍一次，之后由画面显示状态。

性能数据放在对应功能旁边：识别段标 NPU 同载 P95 141 ms；大螺丝掩码段标 P50 7.82 ms；运动段标 5 ms 周期、偏差 P50 0.4 μs；小螺母段标对准 P50 1.61 s。保留指标条件，避免字幕挡住零件和曲线。
