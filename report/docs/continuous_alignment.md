# 板端连续对准：视觉环写入 PL 在线修正通道

主归属评分项：AI PC 与 FPGA/Zynq 协同（20）；PL 修正通道的硬件设计同时支撑 FPGA/Zynq 设计质量（25）。

## 1. 实现了什么

连续对准时，腕部图像在 KV260 内完成定位，计算出的修正量直接写入 PL：**相机帧 → 掩码与定位 → 像素偏差 → 工具平面修正 → 六关节偏移 → PL 修正通道**。大螺丝的掩码预处理使用 PL，其余类别使用 ARM 定位算法。
对准阶段不再每轮等待停稳后另发取图任务，也不经过网络，图像不离开 KV260。AI PC 在规划阶段一次性给出每个关节的偏移限幅、步长和修正矩阵。

覆盖范围（实测）：大螺丝 M12、大螺母 M12、小螺母 M6 走板端连续对准；小螺丝 M6 走停顿对准（三帧 → AI PC → 板端校验）。

## 2. PL 在线修正通道（`src/fpga/rtl/trajectory_stream.sv`）

- 六个关节偏移（Q8.24 rad）在 HLS 求值之后、转浮点之前加到每 5 ms 的设定值上，夹爪轴不参与；
- 硬件限幅：每关节 `|偏移| ≤ limits[j]`（上限 0.25 rad，运行中锁定）；每 5 ms 变化 ≤ `step`（上限 0.003 rad，即 0.6 rad/s）；
- 租约：目标写入即续租，租约过期（上限 0.5 s）则冻结当前偏移；关闭通道时偏移以限速回到零；
- 越界：偏移后设定值越出关节限位，故障码 6，轨迹流停止；
- 非法写入（超上限、未配置即使能、运行中改限幅）一律忽略并计数（`rejects`），不产生总线错误；
- 验证：专用测试平台逐拍检查 179 拍（限幅、步长、租约冻结、关闭回零、越界故障），完整 xsim 回归 16/16 通过（`sim/`，`build/report/rtl_regression_validation.json`）；
  板上寄存器库自检 `PASS_INTERNAL_REGISTER_BANK`（`metrics/scripts/`）。

## 3. 板端视觉环（`board/vision/wrist_vision_loop.py`）

| 环节 | 实现 |
|---|---|
| 取帧 | 本机相机服务，序号去重，只处理新帧 |
| 预处理 | PL 掩码核（大螺丝）；大螺母与小件直接运行与 AI PC 相同的 OpenCV 定位代码（同一帧同一预测点逐帧一致） |
| 控制律 | 位置律：目标 = 拍摄时刻已施加偏移 + 误差对应的修正（补偿图像滞后）；增益 0.5；首帧需第二帧确认；跳变检测扣除机械臂自身运动 |
| 平滑 | 100 Hz 一阶滤波（τ=0.12 s）写入 PL 目标，消除“每帧一个台阶”的停走；主环停止更新超过 0.3 s 则不再续租 |
| 收敛 | 连续 3 帧误差小于阈值且机械臂已到达目标；之后冻结偏移，沿审核过的路径下降、夹取、抬起 |
| 退出 | 抬起后 0.8 s 余弦曲线平滑退回零偏移，再关闭通道 |
| 资源 | 视觉进程固定在 A53 的 2、3 号核，降低优先级，保证运动进程心跳 |
| 守护 | 规划阶段对修正框四角逐一做碰撞审计（含搬运段偏移衰减）；板端使能前校验限幅覆盖修正框 |
