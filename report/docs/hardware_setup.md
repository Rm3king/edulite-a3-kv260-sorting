## 2. KV260 ↔ CAN 收发器接线（PMOD J2）

| KV260 J2 针 | 信号 / FPGA 脚 | 收发器模块 | 方向 |
|---|---|---|---|
| 1 | `can_tx` / H12，LVCMOS33 | CAN_TX | PL → 收发器 |
| 3 | `can_rx` / E10，LVCMOS33 | CAN_RX | 收发器 → PL |
| 9 | GND | GND | 共参考地 |
| 11 | PMOD_3V3 | 3.3V | 板卡 → 模块 |

TX 接 CAN_TX、RX 接 CAN_RX（不按 UART 交叉）。总线侧：模块 CANH → A3 CANH，CANL → A3 CANL，与机械臂控制接口共信号参考地。
终端电阻：模块板载 120 Ω，总线物理两端各保留一个 120 Ω（全总线断电后两端并联约 60 Ω）。
PMOD 只提供 3.3 V（≤100 mA 的收发器供电），机械臂电源不接入 KV260。

## 3. 供电与连接顺序

1. KV260 独立适配器供电，机械臂独立电源供电，两者仅通过 CAN 信号地和差分线相连；
2. 断电完成 PMOD、CANH/CANL 与参考地接线并检查；上电后确认板卡与通信状态；
3. 机械臂上电前放在承托位（托住），开机后由控制台确认再使能。

## 4. 相机安装与标定

- 头部 D435i：固定俯视两个托盘，彩色/深度对齐到彩色，相机到基座的外参由 `live_workflow.json` 中的 `calibration` 路径指定，盒底平面由 `workplane` 指定。
- 腕部相机：安装于末端，图像目标像素与图像雅可比由悬停位姿下的局部标定给出，用于板端闭环纠偏。
