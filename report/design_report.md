# 设计说明

本说明概括系统的任务、软硬件分工和主要结果。完整设计、图表与测量条件见同目录 [tech_doc.pdf](tech_doc.pdf)。文中代码与数据路径均相对仓库根目录。

## 1. 任务与工位

作品《异构协同具身智能机械臂控制系统》面向双托盘中的小型零件分拣。系统识别 M12 大螺丝、大螺母与 M6 小螺丝、小螺母，根据中文指令选择目标，完成对准、抓取、放置和结果核验。

系统由 Ryzen AI PC、Kria KV260、EDULite A3 六轴机械臂和两路相机组成。头部 D435i 提供整幅工位的彩色与深度信息；腕部 UVC 在接近目标后提供近距离图像。上位机统一显示识别结果、任务步骤、逐件状态和中文复核说明。

## 2. 计算分工

AI PC 的 NPU 持续运行 YOLO11n-seg 实例分割，GPU 运行本地 Qwen2.5-VL，CPU 负责三维定位、逆运动学、轨迹规划和几何校验。检测与大模型使用不同的推理单元，减少同时运行时的 GPU 资源竞争。

KV260 的 ARM 处理器校验并管理作业，处理腕部图像、计算偏差和修正量。PL 每 5 ms 求值轨迹并调度 CAN 指令，检查租约、反馈新鲜度与编码范围，对在线修正限幅限速，并加速大螺丝的掩码预处理。七轴跟踪监视器逐帧记录设定与反馈偏差，板端控制程序结合这些状态处理异常。

该分工让 AI PC 集中处理模型推理和规划，让周期执行在板端完成。大模型提供任务描述，机械臂坐标和电机设定由后续程序计算。架构图见 [系统架构](./docs/architecture.md)。

## 3. 一次任务如何运行

1. 操作者输入类别、数量和目标托盘。系统先尝试规则解析，其他表达交给本地千问，再统一校验任务字段。
2. 头部检测提取目标轮廓，结合深度、盒底平面和相机到机械臂的标定结果，计算目标位置与抓取方向。
3. CPU 生成并检查轨迹，将带文件摘要的作业包下发至 KV260。
4. 机械臂接近目标后进行腕部对准。大螺丝、大螺母和小螺母采用板端连续对准；小螺丝采用多帧停顿对准。
5. 对准达到要求后，衔接下降、夹取、搬运和放置。正常返回承托起点后结束本轮使能。
6. 头部相机逐槽核对，再由本地大模型结合图像与记录生成中文说明。

零重力模式支持手动拖动、关节姿态与轨迹记录；数字孪生由实测反馈更新。示教记录为点位配置提供参考，本文的抓取实验使用当前工位配置中的槽位。

## 4. FPGA 的具体贡献

| 模块 | 工作内容 | 对应结果 |
|---|---|---|
| 轨迹求值与 CAN 调度 | 七次多项式求值、七轴设定、截止期队列 | 逻辑分析仪记录 15364 个 5 ms 周期，绝对周期偏差中位数 0.4 µs。 |
| 执行检查 | 租约、反馈新鲜度、编码范围和修正后的关节限位 | 各检查与故障动作见 [接口说明](./docs/interface.md)。 |
| 跟踪监视器 | 被动读取设定帧与反馈帧，逐轴记录偏差 | 内部回环对照中，判定延迟中位数 300.8 ms；ARM 采样判据为 408.1 ms。 |
| HLS 图像核 | 指尖区域填充、高斯滤波、Otsu 阈值与闭运算 | 含 DMA 和缓存维护，耗时中位数 7.82 ms；ARM 单核为 14.43 ms。 |
| 在线修正通道 | 对六关节偏移逐拍限幅限速，并管理修正租约 | 专用测试逐拍检查 179 拍；完整 RTL 回归 16/16 通过。 |

已归档实现结果：PL 100 MHz，LUT 72038、FF 70273、BRAM 7.5、DSP 415；WNS +0.150 ns，WHS +0.011 ns。资源与时序报告位于 `build/report/`。

## 5. AI 与视觉结果

四类分割模型使用本工位数据，在 AI PC 上完成 ROCm 训练与 Quark A8W8 量化。验证集分割掩码 mAP@0.5 为 0.976，mAP@0.5:0.95 为 0.729。

在大模型连续生成的同载测试中，GPU 检测 P95 为 306 ms，NPU 检测 P95 为 141 ms。NPU 与 GPU 的抓取目标对照中，80 帧匹配 270 个三维目标，坐标差异 P95 为 1.1 mm。该差异描述两个推理后端的一致性，末端抓取还经过腕部对准。

板端连续对准的悬停到收敛时间中位数：大螺丝 1.06 s、大螺母 2.43 s、小螺母 1.61 s。早期停顿对准记录的悬停到开始下降时间中位数为 6.67 s，两项的计时终点分别列于 [连续对准说明](./docs/continuous_alignment.md)。

开发记录中的放置确认比例为 83/104（79.8%），按有放置统计的记录汇总；逐件结果见 `metrics/logs/task_trials.csv`。另有完整四件会话的逐槽核验记录。完整指标见 `metrics/metrics.csv`。

## 6. 工程实现与复用

作业按文件摘要发布，板端校验后执行；图像请求使用作业摘要、帧摘要与 nonce 绑定，避免混用任务回复。连续对准的视觉进程和运动进程分别配置处理器核心，降低图像处理对控制心跳的影响。中途保持时，由操作员承托并确认后结束使能。

提交包提供模型、源码、已归档位流、实现报告、原始数据与五项工作流。`build/source_bundle.tar.gz` 包含 FPGA 重建所需的源码和 IP 依赖；已在独立目录完成工程创建与 16 项 XSim 回归。具体命令见 [复现指南](./docs/reproduce.md)。

后续优化围绕小螺丝连续对准、空夹后的自动恢复、机构刚度和示教点位接入规划展开。现有运行记录与失败分类为后续修改提供对照，保留原始数据便于重复评估。
