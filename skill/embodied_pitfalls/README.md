# Skill：机械臂 + KV260 + AI PC 联调踩坑清单

## 适用范围

KV260/Zynq 通过 CAN 驱动关节电机、AI PC 负责视觉与规划的桌面机械臂系统。每条按“触发条件 → 现象 → 定位方法 → 处理”记录，均来自本项目真实故障。

## 使用方法

遇到故障先按“现象”列查找；定位时优先读板端 `execution.log`、`failure_context.json` 与主机端运行目录，不凭现象猜原因。

## 清单

| 类别 | 触发条件 | 现象 | 定位方法 | 处理 |
|---|---|---|---|---|
| 电机参数 | 旧固件经0x458提交未获准的Type18参数（如0x7021） | KV260失联，SSH/ping无响应 | RTL仿真确认白名单拒绝与AXI SLVERR，结合驱动提交路径定位 | ABI 0x60003增加0x45c软拒绝提交及结果寄存器，驱动按版本使用；只在许可条件和范围内调参 |
| 电机上电 | 机械臂断电重启 | 零重力/位置模式启动后无响应 | 读运行模式寄存器 0x7005，重启后复位为 0 | 启动前先写位置模式基线（只写模式，不使能、不改零点） |
| 力矩饱和 | 机械臂伸展姿态下的全速空载段 | `encoder window velocity` 速度监视故障 | 读 `tracking_diagnostics`：电流贴住限值、跟踪误差先增大后追赶超速 | 降低该段速度（本项目 0.8 倍）；不要放宽速度监视 |
| 带载抬升 | 夹着大螺丝以 0.08 m/s 抬升 | J3 跟踪误差增至约 47 mrad 后超速故障 | 同上，J3 电流接近 4.5 A 限值 | 螺丝抬升速度降到 0.05 m/s |
| 温升 | 伸展姿态悬停纠偏 | J2 一次大螺丝升温 16–24 °C，触发温度返回 | 对比每件前后温度 | 开始前温度门 + 运行中强制返回；缩短悬停时间 |
| 内存压力 | 训练与实时检测同时运行 | 检测数降为 0，`synchronized: false` | `free -m` 看 swap；查 `latest.json` 的时间偏差 | 实时运行期间不训练；长时间运行后重启相机管线 |
| 构建 | 同时跑两个 Vivado 构建 | 布线进程被 OOM 杀掉，丢失一小时 | 查内核 OOM 日志 | 25 GB 内存一次只跑一个构建 |
| 界面 | 关闭检测预览窗口 | 检测进程退出，后续抓取取不到帧 | OpenCV `NULL guiReceiver` 异常 | 窗口丢失后转为无界面继续运行 |
| 进程 | 用 `pkill -f` 按模式停进程 | 误杀自身 shell 或其他服务 | 核对命令行匹配范围 | 只按 PID 停止；查进程用 `pgrep -f "[x]yz"` 避免自匹配 |
| 结束流程 | 用终止信号结束零重力 | PL 残留故障位 | 读板端日志，清理流程被打断 | 写控制标记，由板端自行完成结束序列 |
| 运行目录 | 确认“已托住”后写标记 | 标记写进了上一次运行目录，机械臂不失能 | 对比标记路径与当前拥有者进程目录 | 按当前拥有者进程定位运行目录，并补测试 |
| 夹爪判空 | 小螺丝夹持后读夹爪角度 | 夹住的 M6 螺丝被判为空夹 | 读 `JAW_OUTCOME`：夹住约 1.57–1.60，空夹 ≥ 1.64 | 按零件设置空夹判据 |
| 视觉歧义 | 腕部视野里两个 M6 螺丝相距 < 约 8 cm | “两帧不一致”拒绝对准 | 离线回放保存的腕部帧 | 摆放间距 ≥ 8 cm；保留歧义拒绝 |
| 深度缺失 | 小螺母深度测不出且离目标 < 260 px | 规划被几何检查拒绝 | 查 `geometry.log` | 重新取帧或移开该零件；不放宽距离 |
| 红外干扰 | 头部 D435i 红外投射器开启 | 腕部图像出现亮点，小螺丝掩码粘连 | 对比投射器开关前后的腕部帧 | 小螺丝走停顿对准；或加红外滤光片 |
| 总线反馈 | 运行中七个电机反馈同时过期 | PL 故障 8，输出停止，等待托住 | 只读脚本确认七个电机都能应答 | 托住后失能；检查 CAN 线、接头与供电接触 |
| 逻辑分析仪 | CAN-H 阈值设为 3.0 V | 部分电机（4–7 号）的帧解码失败 | 看各节点 CAN-H 显性电平，这些节点幅度偏低 | 阈值改为 2.8 V、50 MHz；只统计本控制器发出的帧 |

## 失效条件

清单针对本项目的硬件（EDULite A3、KV260、D435i、OV9281）与软件版本；更换电机或固件后，参数值（电流限、角度阈值、温升）需要重新测量，方法仍然适用。

## 来源

全部条目来自 2026 年 10 月至 11 月的真实运行记录与故障排查；每条在项目日志、运行目录或测试中可追溯。

该参数提交修复已进行板端拒绝、受限写读恢复及900次ping检查；对应代码见 `board/software/canctl.py` 的 `SAFE_SUBMIT_ABI` 和 `src/fpga/rtl/can_engine.sv`。此条说明该提交故障的处理，不表示所有网络故障都由同一原因造成。
