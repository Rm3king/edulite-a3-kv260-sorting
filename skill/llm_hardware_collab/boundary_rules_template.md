# 项目说明（智能体常驻上下文模板）

## 审阅入口
先读 README 与关键设计文档，再按任务追到原始证据与源码。用中文答复。优先减少真实开销与错误状态转换，不用放宽保护来代替解决问题。

## 授权边界
- 已授权：<例：正常完整返回起点并确认反馈后自动失能>。
- 未授权：<例：中途悬空、故障保持或无法确认返回时自动撤力矩；软件异常时无条件复位；自动 JTAG；修改零点或电机 Flash>。
- 物理动作（上电、使能、托住确认）只由操作员执行；智能体只做只读查询、测试与离线分析，除非本轮明确授权。
- 进程只按 PID 停止；启动的服务登记拥有者，结束时清理。

## 不可覆盖的事实
<按“事实 + 证据路径”逐条写。例：>
1. <某功能当前实现方式，不是另一种更强的方式>。
2. <某早期结论已撤回，原因与新的测量>。
3. <某指标尚未达到某阈值，当前用何种方法补偿>。

## 答复格式
先列证据支持的根因和未证实的假设；每条给出文件/函数/数据、最小修改、离线验证、物理验收和回退方法。不要一上来重写架构。
