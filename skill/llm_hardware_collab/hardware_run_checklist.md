# 上机检查清单

## 上机前（智能体，只读）
- [ ] 板卡在线，PL 位流版本正确，控制/故障寄存器为 0，无残留拥有者进程。
- [ ] 相机服务与隧道在线，检测程序帧同步正常、检测数 > 0，主机内存与交换空间无明显压力。
- [ ] 电机温度低于开始门限。
- [ ] 本轮要改的代码已有离线测试并通过。

## 上机前（操作员）
- [ ] 机械臂托住在起点，急停可用。
- [ ] 场景摆放满足视觉前提（零件间距、无遮挡）。
- [ ] 在控制台确认“已托住”。

## 运行中
- [ ] 智能体只盯事件流与故障，状态变化时报告；出现保持状态先提示操作员托住。

## 运行后
- [ ] 正常返回：确认反馈后失能；异常：操作员托住确认后再失能。
- [ ] 归档运行目录（日志、结果、图像），把新故障写入踩坑清单。
- [ ] 清理本轮启动的进程（按 PID），确认无残留。
